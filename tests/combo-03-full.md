## Q24
<div class="stem"><p>Which of the following statements are logically equivalent?</p> <p>A. Some non-cats are dogs.</p> <p>B. Some cats are not dogs.</p> <p>C. Some non-dogs are non-cats.</p> <p>D. Some non-dogs are not non-cats.</p> <p>Choose the most appropriate answer from the options given below:</p></div>

## Q24 - Options
(A) A, B, and C Only
(B) A and C Only
(C) C and D Only
(D) B and D Only

## Q24 - Hint
**Answer:** B  
**Topic:** Logical Reasoning – Immediate Inference

Reduce each statement using **conversion** (swap terms, valid for I-propositions) and **obversion** (change quality and negate the predicate):

- **A.** Some non-cats are dogs → convert → *some dogs are non-cats* → obvert → **some dogs are not cats**
- **B.** Some cats are not dogs → obvert → *some cats are non-dogs* → convert → **some non-dogs are cats**
- **C.** Some non-dogs are non-cats → obvert → **some non-dogs are not cats**
- **D.** Some non-dogs are not non-cats → obvert → **some non-dogs are cats**

B and D reduce to the same proposition.

> **⚠ Note:** By standard immediate inference, **B and D** are equivalent, which is option **(D)**. A and C (the key's pick) are not equivalent.

- **M2** accepts (0+1)\* 11 (0+1)\* = strings containing **"11"**.
- **M1:** from the start, 0 loops; 1 goes to the middle state; from there 1 reaches the accepting trap, while 0 goes back to start. So M1 also accepts exactly the strings containing **"11"**.

L1 = L2 ⇒ (A) true; L1 ∩ L2' = L1 − L2 = ∅ ⇒ (B) true. (C) is false since L1 ∪ L2 = L1.
